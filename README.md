# br-llm-clients

Provider clients for LLM calls: send a system prompt, tools and a chat history from `br-llm-messages`, get the reply. Two crates, versioned separately, each released by its own git tag `{crate}/v{version}`:

- `br-llm-clients-contract` — the contract: provider-neutral request, reply and client port.
- `br-llm-clients` — the provider clients, built on the contract.

**Status: scaffold.** Both crates are at `0.0.0` and hold no code. No tag has shipped yet.
